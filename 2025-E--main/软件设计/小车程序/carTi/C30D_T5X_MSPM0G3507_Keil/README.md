# MSPM0G3507 双电机 T5X 小车

这是当前硬件的最小 Keil 工程，仅保留：

- 两路 AT8236 电机驱动与两路编码器闭环
- 两轮差速运动控制和六路 ADC 巡线
- UART1 命令/遥测、按键、LED、蜂鸣器
- 上电低电平、限幅、斜坡、换向死区、堵转和方向异常保护

CAN 配置和初始化实现保留，但当前示波器测试固件不会启动 CAN。

当前 `main.c` 保留 PWM 示波器测试：PA0、PA1 均输出 800 Hz、20% 占空比，
PA22、PB13 保持低电平；同时通过 I2C0 连续读取 MPU6050。闭环、巡线和通信应用
源文件暂时不参与 Keil 编译。

## 电机引脚

| 信号 | 引脚 |
|---|---|
| 左电机 IN1 / IN2 | PA1 / PB13 |
| 右电机 IN1 / IN2 | PA0 / PA22 |
| 左编码器 A / B | PA2 / PA8 |
| 右编码器 A / B | PB14 / PB15 |

## MPU6050 接线与验证

| MPU6050/H20 | 信号 | MSPM0G3507 |
|---|---|---|
| 1 | VCC | +5 V（仅限支持 5 V 输入的模块） |
| 2 | GND | GND，必须与主控共地 |
| 3 | H_SCL | PA31 / I2C0_SCL |
| 4 | H_SDA | PA28 / I2C0_SDA |
| 5～8 | 未使用 | 不连接 |

I2C0 配置为 400 kHz，MPU6050 地址为 `0x68`（AD0 低电平）。程序上电校验
`WHO_AM_I == 0x68`，并约每 10 ms 更新一次数据。可在 Keil Watch 中查看：

- `g_mpu6050_ready`：初始化和器件身份校验是否成功
- `g_mpu6050_last_read_ok`：最近一次六轴读取是否成功
- `g_mpu6050_raw`：加速度、温度和陀螺仪原始值

图中 `+5V` 只适用于带稳压且明确支持 5 V 供电的 MPU6050 模块。裸 MPU6050
芯片不能直接接 5 V；还要确认模块不会把 SDA/SCL 上拉到 5 V。无法确认时请给模块
供 3.3 V，并确保 SDA/SCL 上拉到 3.3 V。

## 编译与下载

打开 `Keil/C30D_T5X_MSPM0G3507.uvprojx`，执行 Rebuild。输出文件为
`Keil/Objects/C30D_T5X_MSPM0G3507.hex`。

首次验证请断开电机电源，只给主控供电并测量四个驱动输入；确认停止状态均为低电平后，
再使用限流电源连接电机。软件保护不能替代 AT8236 电源去耦、共地、接线和限流检查。
