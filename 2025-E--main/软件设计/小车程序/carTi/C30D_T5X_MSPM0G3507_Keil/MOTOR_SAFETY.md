# AT8236 电机驱动安全说明

当前 HEX 是示波器专用 PWM 测试固件，不运行闭环控制。PA0 与 PA1 固定输出
800 Hz、20% 占空比；对应的另一侧输入 PA22 与 PB13 固定为低电平。

CAN 配置和初始化实现保留在工程中，但本测试固件不调用。闭环、巡线和通信应用
源文件也暂时不参与编译。

## 首次通电必须这样做

1. 先拔掉电机，只给 MCU 和 AT8236 逻辑电源供电。
2. 先断开电机电源，用示波器检查 PA0、PA1 为 800 Hz/20%，PA22、PB13 为低电平。
3. 电机电源使用带限流功能的实验电源，从低电压和小电流开始，不要直接接满电电池。
4. 一次只接一个电机并悬空车轮，确认方向、编码器反馈方向和电流正常后再接另一个。
5. 若不接电机仍发热、冒烟或电源限流，立即断电并检查 VM/VCC/GND 接反、焊接短路、芯片方向、供电电压和外围器件；这不是软件可以修复的问题。

## 重要维护事项

- `Keil/ti_msp_dl_config_keil.c` 包含上电强制拉低 AT8236 输入的人工安全修改，不能被 SysConfig 生成文件直接覆盖。
- `Config/carTi_MSPM0G3507.syscfg` 中电机 PWM 定时器必须保持 `timerStartTimer = false`；由 `main.c` 在输入状态安全后启动。
- AT8236 输入端应安装硬件下拉电阻。MCU 复位到 GPIO 初始化之间存在纯软件无法消除的高阻窗口。
- 调试打断点或单步前必须先断开电机电源；CPU 暂停后软件堵转保护无法执行，定时器也不能保证把桥输入安全拉低。
- 固定 20% 测试占空比不能代替电流采样、保险丝、限流电源、合适的电机电压和足够的散热。
